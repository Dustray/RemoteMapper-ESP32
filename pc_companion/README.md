# RemoteMapper PC Companion (本地脚本扩展守护程序)

通过在 ESP32 WebUI 中将遥控器按键映射为 F13 ~ F24 无冲突按键，本程序可在电脑后台以 0.0% CPU 占用 实时监听并异步执行本地自定义脚本。

## 快速使用方法

### 第一步：在 WebUI 中将遥控器按键配置为 F13 ~ F24
1. 电脑浏览器打开 WebUI (http://192.168.2.179 或 http://192.168.4.1)；
2. 点击想绑定的遥控器按键（例如 菜单键、电视键、电源键 或任意按键）；
3. 在弹出的高级下拉菜单中，选择 ??? 本地自定义脚本专用键 (F13 ~ F24 无冲突)（例如 F13 或 F14 等）；
4. 点击 保存映射。
